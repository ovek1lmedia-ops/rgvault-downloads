# RGVault — Downloads

Official download page for **RGVault**, an unofficial RedGifs client for Android.
No account needed. Free. Get the APK below or from the
[mirror on our support site](https://support-my-innovation.netlify.app/).

> Unofficial project — not affiliated with or endorsed by RedGifs.

## Which file do I download?

| File | Who it's for |
|---|---|
| `rgvault-vX.Y.Z-arm64-v8a.apk` | **Almost everyone.** All modern phones (anything from the last ~8 years). Download this one. |
| `rgvault-vX.Y.Z-armeabi-v7a.apk` | Very old 32-bit devices only. |

## Install (sideload)

1. Download the `arm64` APK on your phone.
2. Open it — Android will ask you to allow installs from your browser/file manager. Allow it (one-time).
3. Tap **Install**. Updates install the same way, right over the old version —
   your likes, history and settings are kept.
